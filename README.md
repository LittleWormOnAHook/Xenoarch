# Xenoarch

Unity 6 (URP) first-person sci-fi archaeology game. Namespace `DMI.Xenoarch`.
Project code and content live in `Assets/_Project`.

## Vendor packages (not in git, import locally)

Large third-party packages are excluded by `.gitignore`. After cloning, import these
into the project before opening the scenes:

| Package | Folder |
|---|---|
| Digger PRO | `Assets/Digger` |
| FPS Starter Pack | `Assets/FPS_Starter_Pack` |
| Creepy Cat - 3D Scifi Kit Vol 3 | `Assets/_Creepy_Cat` |
| Fast Play (`ca.tim-cstj.fast-play`) | `Packages/ca.tim-cstj.fast-play` (embedded package, tracked) |

Unity packages from the registry restore from `Packages/manifest.json`.
