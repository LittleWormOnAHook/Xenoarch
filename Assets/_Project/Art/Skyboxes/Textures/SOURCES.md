# Sky textures

## Sky_MilkyWay_8k.jpg
NASA/Goddard Space Flight Center Scientific Visualization Studio, **Deep Star Maps 2020**
(https://svs.gsfc.nasa.gov/4851), file starmap_2020_8k.exr (celestial coordinates, equirectangular).
Gaia DR2: ESA/Gaia/DPAC. Constellation figures based on those developed for the IAU by Alan MacRobert of Sky and
Telescope magazine (Roger Sinnott and Rick Fienberg) (not used: the plain star map without figures was used).
NASA SVS imagery is public domain / free to use with the credit above (NASA media guidelines); Gaia data credit
ESA/Gaia/DPAC (CC BY-SA 3.0 IGO for the Gaia-derived map). Keep this credit line in the game credits.
Processing: exposure tone-map 1 - exp(-2x), sRGB encode, 8192x4096 JPEG q93 (Python/OpenCV).
